# Паралакс ефект з трьома шарами

Простий паралакс ефект з трьома шарами зображень, які рухаються з різною швидкістю при прокрутці сторінки.

## Структура шарів

### Шар 1 (Передній план)
- **Позиція**: Спереду (z-index: 3)
- **Висота**: 0% - 25% (знизу вгору)
- **Швидкість**: Найшвидший (множник 0.6)
- **Прозорість**: 25%

### Шар 2 (Середній план)
- **Позиція**: Посередині (z-index: 2)
- **Висота**: 15% - 60% (знизу вгору)
- **Швидкість**: Середня (множник 0.4)
- **Прозорість**: 25%

### Шар 3 (Задній план)
- **Позиція**: Позаду (z-index: 1)
- **Висота**: 35% - 100% (знизу вгору)
- **Швидкість**: Найповільніший (множник 0.2)
- **Прозорість**: 25%

## Як використовувати

1. Відкрийте `index.html` у браузері
2. Прокрутіть сторінку вниз/вгору, щоб побачити паралакс ефект
3. Зображення будуть рухатися з різною швидкістю, створюючи ефект глибини

## Налаштування

### Зміна зображень
У файлі `index.html` знайдіть класи `.layer-1`, `.layer-2`, `.layer-3` та змініть значення `background-image`:

```css
.layer-1 {
    background-image: url('ваше-зображення-1.jpg');
}
```

### Зміна прозорості
Змініть значення `opacity` для класу `.parallax-layer`:

```css
.parallax-layer {
    opacity: 0.25; /* Від 0 (повністю прозоре) до 1 (непрозоре) */
}
```

### Зміна швидкості паралаксу
У JavaScript секції змініть множники для кожного шару:

```javascript
layer1.style.transform = `translateY(${scrolled * 0.6}px)`; // Змініть 0.6
layer2.style.transform = `translateY(${scrolled * 0.4}px)`; // Змініть 0.4
layer3.style.transform = `translateY(${scrolled * 0.2}px)`; // Змініть 0.2
```

## Технології
- HTML5
- CSS3
- Vanilla JavaScript
